Terms of service

Authorized use

Whale Backup is a private operations tool for authorized operators of the whale identification service. Connect only a Google account and application data that you have permission to use for backup and restoration.

Operator responsibilities

The operator is responsible for protecting local credentials and encryption keys, controlling access to Drive, providing sufficient storage, selecting an appropriate backup frequency and retention policy, and verifying recovery. A backup is not a substitute for checking that restoration works.

Cloud backup scheduling is enabled only after validation. Backups cannot run while the required computer or Docker environment is stopped; the configured scheduler must handle missed runs after startup.

Recovery and availability

Recovery depends on a valid backup, compatible runtime artifacts, and the correct decryption password. Keep that password securely outside the computer being backed up. Storage-provider outages, insufficient space, revoked access, or loss of the password can prevent backup or recovery.

Privacy and support

Use of the Google Drive integration is described in the privacy policy. For help, contact the support address shown on Google's consent screen or your existing service support channel.
