Whale Backup is being configured to create encrypted recovery backups for a whale identification service and store them in the operator's Google Drive.

Backup scheduling and cloud restoration are being validated. They are enabled only after recovery checks succeed.

What the tool does

The planned backup covers application databases, research images, inference history, model and search-index artifacts, and the configuration needed to restore the service. Development and production use separate backup repositories and encryption keys.

Backup frequency is configurable. Recovery checks use a separate restore environment so that validation does not overwrite the running service.

Why Google authorization is requested

An authorized operator connects their Google account so the local tool can create, upload, read, and verify its backup files in Google Drive. The requested drive.file scope limits access to files created by or explicitly granted to this app. The tool does not request access to unrelated Drive files.

Backup contents are encrypted locally before upload. Google OAuth credentials and the repository encryption password are kept separately from the uploaded backup.

Who it is for

This is a private tool for authorized operators of the whale identification service. This informational website does not provide a sign-in, collect backup files, or expose the application or its private network.
